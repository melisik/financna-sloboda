# Checklist ručných overení na iPhone (D-325)

Robí zakladateľ na vlastnom iPhone v súkromnom náhľade alebo vo verejnej verzii pridanej na plochu. Len testovacie alebo vymyslené údaje. Výsledok zapíš do tabuliek (ok / nie / poznámka) a pošli mi ho; zapíšem ho do rozhodnutí.

## A. Uchovanie dát po 7 dňoch neaktivity (D-042, `docs/06` oddiel 9, M2)

| # | Krok | Výsledok |
|---|---|---|
| A1 | Appka je pridaná na plochu (nie len otvorená v Safari). Otvor ju z plochy. | |
| A2 | Nahraj testovaciu zálohu; zapíš si počet transakcií v histórii (nie sumy). | |
| A3 | Ulož zálohu do Súborov (pre istotu). | |
| A4 | Dátum začiatku (dnes): | |
| A5 | **7 dní** appku neotváraj (ani Safari s adresou appky). | |
| A6 | Po 7 dňoch otvor appku z plochy. Sú údaje na mieste (rovnaký počet transakcií, nastavenia)? | |
| A7 | Ak údaje zmizli: obnov zo zálohy z kroku A3 a napíš mi, koľko dní prešlo a aká je verzia iOS. | |

## B. VoiceOver (M6, `docs/07` oddiel 9)

Zapnutie: Nastavenia → Prístupnosť → VoiceOver (alebo trikrát stlačiť bočné tlačidlo, ak je skratka). Ovládanie: potiahnutie doprava = ďalší prvok, dvojité ťuknutie = aktivácia.

| # | Úloha | Prečíta VoiceOver zrozumiteľne? | Dá sa dokončiť? |
|---|---|---|---|
| B1 | Prehľad: prečítaj dátum cieľa. | | |
| B2 | Menu: prejdi na Peniaze → Transakcie. | | |
| B3 | Zapíš rýchly výdavok (suma, kategória, Uložiť). Prečíta sa potvrdenie „Zapísané…“? | | |
| B4 | Nákup po položkách: pridaj položku, použi + a −. Prečítajú sa názvy tlačidiel (napr. „Viac: chlieb“)? | | |
| B5 | Vyhodnotenie: zadaj hodnoty a ulož. | | |
| B6 | Záloha: Uložiť zálohu. | | |
| B7 | Čo bolo najťažšie (jedna veta): | | |

Trvanie: A je 5 minút na začiatku a 2 minúty po týždni; B asi 15 minút.
