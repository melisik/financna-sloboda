# 69 – Kandidáti na názov appky

> Stav: **otvorené** (2026-10-26). Pracovný názov „Finančná sloboda" nefunguje pre modulárnu appku (D-337). Toto nie je rozhodnutie – je to evidencia kandidátov pred rozhodnutím zakladateľa.

## Kontext

Appka rastie za pôvodný rámec finančnej nezávislosti (sklad, recepty, ďalšie moduly). Nový názov musí:

- fungovať v slovenčine aj angličtine (rovnako alebo veľmi podobne),
- nenavádzať na to, že appka rieši iba financie,
- byť bez negatívnych ani neúmyselných asociácií,
- byť unikátny a registrovateľný ako doména.

## Shortlist (október 2026)

### Compaven ⭐ vedúci kandidát

| | |
|---|---|
| **Zloženie** | Com(pass) + (ha)ven |
| **Výslovnosť** | *kom-PAY-ven* |
| **SK/EN** | identické slovo |
| **Metafora** | navigácia (compass) k bezpečnému zázemiu (haven) |
| **Doména** | žiadny existujúci produkt ani spoločnosť s týmto názvom nenájdený (2026-10-26) |

**Výhody:** bezpečné, unikátne, foneticky príjemné, SK/EN rovnaké, žiadne negatívne asociácie.

**Riziko:** anglický rodený hovorec môže pri prvom počutí asociovať *compact van* alebo *campervan* (výsledky vyhľadávania ukazujú túto fonetickú blízkosť). Nie je to bloker, ale treba overiť pri testovaní s anglicky hovoriacimi používateľmi.
